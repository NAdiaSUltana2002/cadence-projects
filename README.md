# Cadence Projects

This repository contains selected Cadence Virtuoso design projects and reports completed as part of my VLSI and circuit design coursework.

## Projects Included

### 1. 4-Bit Comparator
Design, simulation, and verification of a 4-bit magnitude comparator using Cadence Virtuoso.

### 2. CMOS 2-Input NAND Gate
CMOS logic gate design and simulation using Cadence Virtuoso.

### 3. DC Analysis of Inverter Symbols
DC analysis and simulation of CMOS inverter-based circuit symbols.

## Tools Used

- Cadence Virtuoso
- CMOS Design Flow
- Schematic Design
- Simulation and Verification

## Purpose

The purpose of this repository is to organize my Cadence-based academic design work in a clean and accessible format for research and academic applications.
